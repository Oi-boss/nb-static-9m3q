# 天赋自查 · 自我观察测评 —— 对外页面仓

本仓只放一个对外文件：`index.html`。买家付款后拿到的链接就是本页。

## 这个仓是干什么的

- 一个商品＝一个仓＝一个页面（本店固定做法，便于审计「买家实际看到什么」）。
- 页面在浏览器本地完成出题、计分、结果与分享图，**不请求任何外部接口、不加载外部脚本、不埋点、断网也能做完**。
- 母本（题库工作件、六型结果页文案、生成器与全部自检脚本）**不进这个仓**；仓里只有对外成品。

## 一商品一仓

- 本仓只服务「天赋自查」这一个商品，不与店里其它商品共用仓、共用域名根路径或共用浏览器存储键。
- 存档键：`tianfu_answers_v1`，与内耗指数品的键不同，两边进度互不覆盖。

## 禁入仓项

- 母本与历史工作件（题源、审查记录、登记台账）。
- 任何带真人作答数据的回收表。
- 账号、密钥、店铺凭证。

## 页面口径

- 48 题 / 6 个维度 / 每题 5 档；计分的档位切线在上线前已预注册锁死，上线后不为「分布好看」而改线。
- 解锁档位当前为 **1 档**（只有基础档，无升级档；后续是否加档由店铺另行裁定）。
- 结果解读是娱乐向的自我观察：**不是诊断，不做能力或岗位匹配，不给任何人打分排名**。页脚四句声明在每一种结果的页面底部逐字出现。
